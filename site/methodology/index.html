Selection and ranking

For each country and indicator, the build requests the World Bank series and preserves the newest 15 non-null observations with their actual observation years. Rankings compare the latest of those source observations from highest to lowest. Missing values remain missing: the pipeline does not substitute zero, interpolate, forecast, or otherwise invent observations.

Derived metrics

Calculated metrics are displayed separately from World Bank source facts. Five-year and 10-year percentage change compare the latest observation with an observation from exactly five or 10 calendar years earlier. If that exact year is absent or the starting value is zero, the result is unavailable. CAGR uses the same exact endpoints and is calculated only when both endpoint values are positive.

Limitations

Countries and indicators can have different latest observation years because reporting schedules vary. The year shown beside every value is part of the result and should be considered when making comparisons. Indicator definitions and revisions remain under World Bank stewardship.
