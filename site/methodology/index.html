Selection and ranking

For each country and indicator, the build requests a recent multi-year window and selects the latest non-null observation. Rankings compare those selected values from highest to lowest. Missing values remain missing: the pipeline does not substitute zero, interpolate, forecast, or otherwise invent observations.

Limitations

Countries and indicators can have different latest observation years because reporting schedules vary. The year shown beside every value is part of the result and should be considered when making comparisons. Indicator definitions and revisions remain under World Bank stewardship.
