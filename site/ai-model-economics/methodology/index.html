Methodology

Canonical facts come only from allow-listed official provider documentation and announcements. No AI-generated inference becomes canonical data.

Pricing normalization

Source prices are accepted only in explicit USD-per-token, USD-per-1,000-token, or USD-per-1,000,000-token units, then normalized to USD per 1M tokens. Standard synchronous list pricing is used. Batch, cache, priority, and long-context prices are excluded unless the observation explicitly names that tier.

Configured workload

blended-workload-v1 uses 800,000 input tokens and 200,000 output tokens. Formula: input price × input tokens / 1M + output price × output tokens / 1M.

Intelligence per dollar

intelligence-per-dollar-v1 divides one eligible benchmark score by the configured blended workload cost. It includes only: agents-last-exam-v1. Values are compared only inside the same benchmark version, unit, evaluation configuration, and comparison group. Unrelated benchmarks are never averaged into a composite.

Publication gates

A model page needs canonical identity, provider, release, status, openness, context, current input/output pricing, complete dated provenance, deterministic insight evidence, valid canonical URL, and internal links. Comparisons also require compatible pricing units, prices no more than 120 days old, and complete provenance. Missing or incompatible benchmark evidence suppresses performance claims without inventing a result.
