Transparent by design

Methodology

Canonical facts come only from allow-listed official provider documentation and announcements. No AI-generated inference becomes canonical data.

Catalog taxonomy

Models may be API, hosted, open-weight, local, product-only, or preview distributions, and may have more than one distribution. Availability and capability fields can remain unknown when an official source does not establish them. Open-model parameter, architecture, quantization, and hardware fields are optional; hardware is never estimated.

Pricing normalization

Pricing is optional. Source prices are accepted only in explicit USD-per-token, USD-per-1,000-token, or USD-per-1,000,000-token units, then normalized to USD per 1M tokens. Cached input is retained separately when published. Models without comparable public API input and output pricing are shown in the catalog and excluded from price rankings.

Configured workload

{{ site.blended_workload.formula_version }} uses {{ site.blended_workload.input_tokens|tokens }} input tokens and {{ site.blended_workload.output_tokens|tokens }} output tokens. Formula: input price × input tokens / 1M + output price × output tokens / 1M.

Intelligence per dollar

{{ site.intelligence_per_dollar.version }} divides one eligible benchmark score by the configured blended workload cost. It includes only: {{ site.intelligence_per_dollar.included_benchmarks|join(', ') }}. Values are compared only inside the same benchmark version, unit, evaluation configuration, and comparison group. Unrelated benchmarks are never averaged into a composite.

Publication and ranking gates

A model page needs canonical identity, provider, useful taxonomy and availability metadata, complete dated provenance, deterministic insight evidence, a valid canonical URL, and internal links. Release date, context, pricing, and benchmarks may be absent. Price rankings require comparable API pricing; context ranking requires a verified context window; benchmark eligibility is evaluated per benchmark. Comparisons also require compatible pricing units, prices no more than {{ site.maximum_pricing_age_days }} days old, and complete provenance.
