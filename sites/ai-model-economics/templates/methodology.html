Methodology

Canonical facts come only from allow-listed official provider documentation and announcements. No AI-generated inference becomes canonical data.

Pricing normalization

Source prices are accepted only in explicit USD-per-token, USD-per-1,000-token, or USD-per-1,000,000-token units, then normalized to USD per 1M tokens. Standard synchronous list pricing is used. Batch, cache, priority, and long-context prices are excluded unless the observation explicitly names that tier.

Configured workload

{{ site.blended_workload.formula_version }} uses {{ site.blended_workload.input_tokens|tokens }} input tokens and {{ site.blended_workload.output_tokens|tokens }} output tokens. Formula: input price × input tokens / 1M + output price × output tokens / 1M.

Intelligence per dollar

{{ site.intelligence_per_dollar.version }} divides one eligible benchmark score by the configured blended workload cost. It includes only: {{ site.intelligence_per_dollar.included_benchmarks|join(', ') }}. Values are compared only inside the same benchmark version, unit, evaluation configuration, and comparison group. Unrelated benchmarks are never averaged into a composite.

Publication gates

A model page needs canonical identity, provider, release, status, openness, context, current input/output pricing, complete dated provenance, deterministic insight evidence, valid canonical URL, and internal links. Comparisons also require compatible pricing units, prices no more than {{ site.maximum_pricing_age_days }} days old, and complete provenance. Missing or incompatible benchmark evidence suppresses performance claims without inventing a result.
